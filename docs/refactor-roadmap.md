# WWords 重构路线图

## 阶段 1：建立安全底座

目标：先修最危险的问题，避免在旧架构上继续堆功能。

交付：

- 应用工厂和统一配置入口
- AI 配置脱敏
- AI 补全鉴权
- 词条输入校验
- 基础测试修复

状态：进行中

## 阶段 2：重整后端边界

目标：把“路由即业务”的结构拆开，建立可持续演进的模块边界。

交付：

- Alembic 迁移体系
- service/repository 分层
- schema 拆分
- 统一错误模型
- 统一配置模型
- review session 机制

## 阶段 3：迁移前端到 Next.js

目标：用新的前端承载真实业务，而不是只做视觉外壳。

交付：

- Next.js App Router 基础工程
- Tailwind 设计 token
- shadcn/ui 风格组件层
- 登录注册页
- Dashboard 工作台
- 复习交互流
- 后台配置页

## 阶段 4：联调与发布

目标：从“能写代码”提升到“能交付上线”。

交付：

- 前后端联调说明
- Docker / Compose 更新
- README 重写
- 回归测试矩阵
- 发布说明与迁移说明

## 当前优先级

### 第一优先级

- 安全边界
- 配置模型
- 认证语义
- 前端新骨架可运行

### 第二优先级

- 复习规则可信化
- 测试体系补齐
- 页面实装

### 第三优先级

- 性能与体验优化
- 管理能力扩展
- CI/CD 完整化
